# Fish bot v3.2

Бот для автоматической рыбалки в World of Warcraft (проверялся на WoW: Forever с аддоном
SKTools → Easy Fishing).

Бот нажимает клавишу заброса, ждёт поклёвку, нажимает клавишу подсечки, выжидает
случайную паузу и забрасывает снова. Периодически делает «перерывы на кофе» случайной
длины. Мышь не трогает (в режиме по звуку).

Поклёвку бот определяет одним из двух способов (`detect_mode`):

- **`"sound"` (по умолчанию, рекомендуется)** — по всплеску в звуке **самой игры**. Бот
  читает громкость только процесса `Wow.exe` (как в «Микшере громкости» Windows), поэтому
  Discord, браузер, музыка в плеере ему **не мешают**. Освещение, погода и графика на этот
  способ не влияют.
- **`"image"`** — по картинке поплавка (`float.png`), как в старых версиях. Плохо работает с
  динамическим освещением.

## Требования

- Windows 10 или 11, 64-бит.
- Установка Python **не нужна** — всё внутри `FishBot.exe`.
- Аддон, который подсекает клавишей (например SKTools → Easy Fishing), или встроенная
  в игру функция «Interact Key».

## Файлы

| Файл | Зачем |
|---|---|
| `FishBot.exe` | Сам бот. |
| `settings.json` | Настройки. Должен лежать рядом с exe. Если его нет — бот создаст файл с настройками по умолчанию. |
| `calibrate.bat` | Запуск калибровки звука двойным щелчком. |
| `float.png` | Шаблон поплавка, нужен только для `detect_mode: "image"`. |
| `fishbot.log` | Лог работы, создаётся сам. Пригодится, если что-то пошло не так. |

## Подготовка игры

Делается один раз.

1. **Аддон.** SKTools: `/sk professions` → Easy Fishing → включить и назначить клавишу
   (например `Z`). Эту же клавишу потом укажете в `settings.json` → `key`.
2. **Автолут** (Настройки → Управление → «Автодобыча»): **включить**. Иначе после подсечки
   нужно ещё одно нажатие, чтобы забрать рыбу, а бот этого не делает.
3. **Удочку** наденьте заранее. В SKTools первое нажатие клавиши может надевать удочку или
   ставить приманку вместо заброса — бот это переживёт, но потеряет до 30 секунд.
4. **Звук в игре** (Настройки → Звук):
   | Настройка | Значение | Почему |
   |---|---|---|
   | Музыка | выкл | Музыка поднимает «фон», на котором хуже слышен всплеск. |
   | Звуки окружения (Ambience) | выкл | То же самое: ветер, вода, птицы. |
   | Звуковые эффекты | вкл, громкость 70–100% | Всплеск — это звуковой эффект. |
   | Звук в фоновом режиме | вкл | Чтобы калибровка работала, когда смотрите в консоль. |
   | Общая громкость игры | любая, но не 0 | |

   Громкость Windows и колонок на бота **не влияет**. Даже в наушниках с выключенной
   громкостью бот слышит игру. А вот если выключить звук самой игры — не услышит.
5. **Позиция.** Встаньте у самой воды. Если поплавок упадёт слишком далеко, клавиша
   аддона до него не «дотянется».

## Первый запуск и калибровка

Калибровка — это режим проверки: бот **ничего не нажимает**, только показывает, что он
«слышит». Нужна, чтобы убедиться, что всплеск поплавка заметно громче остального звука.

1. Дважды щёлкните `calibrate.bat`.
2. Переключитесь в игру и порыбачьте **вручную** 5–10 забросов.
3. Поглядывайте на консоль:

   ```
     0.043 фон 0.041 порог 0.123 |##                                    |
   ! 0.412 фон 0.043 порог 0.123 |########################              |
   ```

   | Поле | Что значит |
   |---|---|
   | первое число | громкость игры прямо сейчас (0 — тишина, 1 — максимум) |
   | `фон` | обычная громкость за последние 3 секунды |
   | `порог` | выше этого значения бот посчитает звук поклёвкой |
   | `!` | в этот момент бот подсёк бы |

4. **Хороший результат:** `!` появляется на всплеске поплавка и почти не появляется в
   остальное время. `!` сразу после заброса — нормально, в рабочем режиме первые 1.5 с
   после заброса игнорируются.
5. Нажмите **Ctrl+C** — бот покажет статистику. Если спросит «Завершить выполнение
   пакетного файла [Y(да)/N(нет)]?» — нажмите `N`, чтобы окно не закрылось.
6. Если результат плохой — см. [Типовые проблемы](#типовые-проблемы), поменяйте
   `settings.json` и запустите калибровку снова. Пересобирать ничего не надо.

Из консоли то же самое: `.\FishBot.exe --calibrate`.

## Рабочий запуск и управление

1. Проверьте `key` в `settings.json` (или оставьте `""` — бот спросит при запуске).
2. Запустите `FishBot.exe` и за 5 секунд (`start_delay`) переключитесь в игру.
3. В консоли должно быть примерно так:

   ```
   Режим поклёвки: звук игры
   Звук 'Wow.exe' найден на: Динамики (Realtek ...)
   Заброс #1
   Поклёвка! (звук 0.412, фон 0.043, порог 0.123)
   Поймано: 1/1. Следующий заброс через 6.3 с
   ```

| Действие | Клавиша |
|---|---|
| Пауза / продолжить | **F10** |
| Остановить бота | **F11** |
| Аварийная остановка | увести мышь **в любой угол экрана** |
| Остановить из консоли | **Ctrl+C** |

Если переключиться из игры в другое окно, бот приостановится и не будет нажимать клавиши
«куда попало». Вернётесь в игру — продолжит.

## Как работает бот

```
заброс (key)
  │   image: ищем поплавок (до fishing_rod_restart_first_circle с), не нашли → перезаброс
  ▼
ожидание поклёвки (до fishing_rod_restart_second_circle с)
  │   sound: первые sound_ignore_after_cast с не слушаем (звук самого заброса)
  │   нет поклёвки → перезаброс
  ▼
подсечка (loot_key или key)
  ▼
пауза sleep_after_capture   (рыба лутается)
  ▼
случайная пауза cast_delay  (например 1–10 с)
  ▼
пора на перерыв? → короткий / длинный перерыв
  ▼
заброс ...
```

**Как бот «слышит» поклёвку.** Около 50 раз в секунду бот берёт пиковую громкость игры.
Пока поплавок спокоен, он запоминает «фон» — обычную громкость за последние 3 секунды
(медиана, так что редкие громкие звуки фон не портят). Поклёвка — когда громкость
**два замера подряд** выше порога:

```
порог = max( фон × sound_ratio ,  фон + sound_min_delta )
```

Пример: фон 0.04, `sound_ratio` 3, `sound_min_delta` 0.05 → порог = max(0.12, 0.09) = **0.12**.
Всплеск обычно 0.3–0.6, так что он проходит, а шорох воды — нет.

Порог считается заново под каждый заброс и подстраивается под громкость, поэтому одни и
те же настройки обычно работают на разных компьютерах.

## Все настройки `settings.json`

Общие правила:

- Время — в **секундах**, если в названии не сказано `_minutes`.
- Многие параметры принимают число **или диапазон `[min, max]`** — тогда каждый раз берётся
  случайное значение из диапазона. Например `"cast_delay": [1, 10]`.
- Ключи, которые начинаются с `_` (например `_comment`), — комментарии, бот их пропускает.
- Если параметра нет в файле — берётся значение по умолчанию. При ошибке в файле бот
  пишет, в какой строке и что не так.
- Строки — в двойных кавычках, `true`/`false` — без кавычек, после последнего параметра
  запятой нет.

### Клавиши

| Параметр | По умолчанию | Описание |
|---|---|---|
| `key` | `""` | Клавиша заброса — та же, что в аддоне. `""` — бот спросит при запуске. |
| `loot_key` | `""` | Клавиша подсечки. `""` — та же, что `key` (так работает SKTools и подобные аддоны: одна клавиша на всё). |
| `loot_mode` | `"key"` | `"key"` — подсекать клавишей. `"mouse"` — кликать по поплавку, работает только с `detect_mode: "image"`. |
| `pause_key` | `"f10"` | Пауза. Допустимо: `f1`–`f12`, `pause`, `scrolllock`, `insert`, `delete`, `home`, `end`, `pageup`, `pagedown`, `""` (выключить). |
| `stop_key` | `"f11"` | Остановка. Те же значения, не должна совпадать с `pause_key`. |

**Как записывать клавиши** (`key`, `loot_key`):

| Что | Как писать |
|---|---|
| Буквы | `"z"`, `"f"` — **английская** буква на этой клавише, даже если в игре/Windows русская раскладка. Бот жмёт физическую клавишу, раскладка не важна. |
| Цифры | `"1"` … `"0"` |
| Цифры на NumPad | `"num1"` … `"num0"` |
| F-клавиши | `"f1"` … `"f24"` |
| Прочие | `"space"`, `"tab"`, `"enter"`, `"`"` (ё), `"-"`, `"="`, `"["`, `"]"`, `";"`, `"'"`, `","`, `"."`, `"/"` |
| С модификатором | `"shift+1"`, `"ctrl+z"`, `"alt+f"` |

Русские буквы (`"я"`) бот не примет и подскажет, какую английскую написать.

### Режим

| Параметр | По умолчанию | Описание |
|---|---|---|
| `detect_mode` | `"sound"` | `"sound"` — поклёвка по звуку игры. `"image"` — по картинке поплавка. |
| `window_title` | `"World of Warcraft"` | Бот работает, только пока активно окно, в заголовке которого есть этот текст. `""` — не проверять (не рекомендуется: бот будет нажимать клавиши в любое окно). |

### Звук (`detect_mode: "sound"`) — самое важное

| Параметр | По умолчанию | На что влияет | Когда менять |
|---|---|---|---|
| `sound_process` | `"Wow.exe"` | Чей звук слушать. | Если бот пишет «Звук 'Wow.exe' не найден», а игра запущена: посмотрите имя в Диспетчере задач → «Подробности» (например `WowClassic.exe`). |
| `sound_ratio` | `3.0` | Во сколько раз звук должен быть громче фона. **Главная ручка чувствительности.** | Ложные подсечки → `4`–`5`. Не слышит всплеск → `2`–`2.5`. |
| `sound_min_delta` | `0.05` | Насколько (по шкале 0–1) звук должен быть громче фона минимум. Нужна в тишине: при фоне 0.01 одного `sound_ratio` мало (порог был бы 0.03, сработает от любого шороха). | Ложные подсечки в тихом месте → `0.08`–`0.1`. Всплеск тихий (на калибровке пик < 0.1) → `0.03`. |
| `sound_ignore_after_cast` | `1.5` | Сколько секунд после заброса не слушать: звук заброса тоже громкий. | Бот подсекает сразу после заброса → `2`–`2.5`. |
| `sound_threshold` | `0` | Фиксированный порог (0–1) вместо автоматического. `0` — автоматически. | Обычно не трогать. Пригодится, если фон сильно «гуляет»: поставьте значение чуть ниже пика всплеска из калибровки. |

### Задержки и тайм-ауты

| Параметр | По умолчанию | Описание |
|---|---|---|
| `start_delay` | `5` | Пауза после запуска, чтобы успеть переключиться в игру. |
| `cast_delay` | `[1, 10]` | Случайная пауза между уловом и следующим забросом. `0` — сразу. Чем шире диапазон, тем «человечнее». |
| `sleep_after_capture` | `1` | Пауза сразу после подсечки, пока рыба лутается. Если рыба не успевает попасть в сумку — увеличьте до `1.5`–`2`. |
| `sleep_between_click` | `[0.3, 0.6]` | Сколько удерживается клавиша. Уменьшать ниже `0.05` не стоит: игра может не заметить нажатие. |
| `fishing_rod_restart_second_circle` | `30` | Сколько ждать поклёвку, потом перезаброс. Поплавок в WoW живёт ~20–30 с, больше 30 ставить нет смысла. |
| `fishing_rod_restart_first_circle` | `30` | Только `image`: сколько искать поплавок, потом перезаброс. |

### Перерывы («кофе»)

```json
"short_break": { "enabled": true, "every_minutes": [10, 15], "duration_minutes": [1, 2] },
"long_break":  { "enabled": true, "every_minutes": [55, 65], "duration_minutes": [5, 6] },
"session_limit_minutes": 0
```

| Параметр | Описание |
|---|---|
| `enabled` | `true` / `false` — включить или выключить этот вид перерыва. |
| `every_minutes` | Через сколько **минут** будет перерыв (случайно из диапазона). |
| `duration_minutes` | Сколько **минут** длится перерыв (случайно из диапазона). |
| `session_limit_minutes` | Через сколько минут бот сам остановится. `0` — не останавливаться. Можно диапазон: `[90, 120]`. |

Как это работает:

- Интервал и длительность выбираются заново после каждого перерыва — расписание не повторяется.
- Перерыв не обрывает текущий заброс: бот докидывает и уходит на перерыв перед следующим.
- Если подошли оба перерыва сразу, будет только длинный. После любого перерыва отсчёт
  короткого начинается заново — два перерыва подряд не бывает.
- Длинный считается от запуска: «раз в ~час» независимо от коротких.
- Во время перерыва можно уйти в другое окно. F10 ставит отсчёт перерыва на паузу, F11 работает всегда.

### Картинка (`detect_mode: "image"`)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `monitor1` | `[450, 70, 1200, 710]` | Область экрана для поиска поплавка: `[x, y, ширина, высота]` в пикселях. |
| `region_search` | `[450, 70]` | Смещение найденных координат. Должно совпадать с `x, y` из `monitor1`. `null` — взять из `monitor1`. |
| `similarity` | `0.8` | Насколько поплавок должен быть похож на `float.png` (0–1). Не находит → `0.7`. Находит лишнее → `0.85`. |
| `np_mean_value` | `112` | Порог поклёвки по яркости квадрата поплавка. Подсекает рано → больше, пропускает → меньше. Текущие значения видны при `debug: true`. |
| `np_mean_delta` | `0` | Относительный порог: поклёвка, если яркость выросла на столько по сравнению со спокойным поплавком. Устойчивее к освещению. `0` — использовать `np_mean_value`. Начните с `5`–`10`. |

`float.png` рядом с exe заменяет встроенный шаблон. Вырежьте поплавок со своего экрана
в том же разрешении и графике, в которых играете.

### Логи

| Параметр | По умолчанию | Описание |
|---|---|---|
| `log_to_file` | `true` | Писать лог в `fishbot.log` рядом с exe. |
| `debug` | `false` | Подробный лог: громкость, фон и порог на каждом замере. Включайте для разбора проблем, потом выключайте — лог быстро растёт. |

## Типовые проблемы

| Симптом | Причина | Что сделать |
|---|---|---|
| «Звук 'Wow.exe' не найден» | Игра не запущена, звук игры выключен или другое имя процесса | Запустите игру, включите звук в игре, проверьте `sound_process`. |
| Каждый заброс «Поклёвки нет за 30 с» | Бот не слышит всплеск | Калибровка: виден ли `!` на всплеске? Если нет — громче звуковые эффекты в игре, `sound_ratio` → `2`, `sound_min_delta` → `0.03`. |
| Подсекает раньше времени | Ложные срабатывания на другие звуки игры | Выключите музыку/окружение, `sound_ratio` → `4`, `sound_min_delta` → `0.08`. |
| Подсекает сразу после заброса | Звук заброса принят за всплеск | `sound_ignore_after_cast` → `2.5`. |
| На калибровке `фон` 0.1 и выше | Играет музыка или звуки окружения | Выключите их в игре. |
| Бот пишет «Заброс», но в игре ничего не происходит | Клавиша не совпадает с аддоном, или игра запущена от администратора | Проверьте `key`. Если игра/лаунчер запущены от администратора — запускайте `FishBot.exe` тоже от администратора (Windows не даёт обычной программе нажимать клавиши в окно администратора). |
| «Окно 'world of warcraft' не активно — жду...» | Фокус не на игре | Кликните в окно игры. Если заголовок окна другой — поправьте `window_title`. |
| Рыба подсекается, но остаётся в окне добычи | Выключен автолут | Включите автолут в игре. |
| Антивирус ругается на `FishBot.exe` | Ложное срабатывание на упакованные Python-программы | Добавьте файл в исключения. |
| Окно бота сразу закрывается | Ошибка в `settings.json` | Запустите из консоли или посмотрите `fishbot.log` — там написано, в какой строке ошибка. |

Если не помогло: поставьте `"debug": true`, порыбачьте ботом 3–5 забросов и пришлите
`fishbot.log` вместе со статистикой из калибровки.

## Перенос на другой компьютер

Скопируйте папку целиком: `FishBot.exe`, `settings.json`, `calibrate.bat` (и `float.png`,
если нужен режим картинки). Ничего устанавливать не нужно. На новом компьютере:

1. Настройте игру по разделу [Подготовка игры](#подготовка-игры) — у каждого свои
   настройки звука и свой аддон/клавиша.
2. Запустите `calibrate.bat` и проверьте всплеск. Громкость у всех разная, но порог
   автоматический, поэтому обычно подходят настройки по умолчанию.
3. Проверьте `key` — он должен совпадать с клавишей в аддоне.

От чего бот **не зависит**: раскладка клавиатуры, разрешение экрана, видеокарта, какие
колонки/наушники выбраны (бот ищет звук игры на всех устройствах вывода), громкость Windows.

## Сборка из исходников

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt pyinstaller
.\.venv\Scripts\python main.py              # запуск без сборки
.\.venv\Scripts\python main.py --calibrate  # калибровка

# сборка exe
.\.venv\Scripts\pyinstaller --noconfirm --clean --onefile --console --name FishBot `
    --add-data "float.png;." --add-data "settings.json;." main.py
# результат: dist\FishBot.exe
```
